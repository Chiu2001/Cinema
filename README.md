# Project Name: ConcertProject

[![Java](https://img.shields.io/badge/language-Java-brightgreen)](https://www.oracle.com/java/)

## Project Introduction
This project implements a movie ticket booking website, including a movie home page, login, registration, purchasing movie tickets with seat selection, a shopping cart, third-party login, third-party payment (ECPay, LinePay), and an admin system, all aimed at improving the user's ticket-purchasing experience.


## System Architecture
1. Web Frontend
   - User login, Google login
   - Admin backend (list/delist movies)
   - Movie seat selection
   - Third-party payment (ECPay, LinePay)

2. Backend
   - Implements seat reservation when purchasing tickets
   - Spring Security protection
   - RESTful-style API design
   - CRUD database operations
